# Smart Transport Box

An IoT prototype for monitoring transport conditions, recording
temperature excursions and handling events, and generating
journey reports.

## Current status
Day 1: project foundation and automated testing.

## Planned capabilities
- ESP32 sensor acquisition
- BLE mobile connectivity
- Wi-Fi and MQTT telemetry
- Raspberry Pi edge backend
- SQLite persistence
- Rule-based alerts and ML risk prediction
- Admin dashboard
- Docker, CI/CD, and local Kubernetes

## Safety note
This prototype is not a certified food-safety or medical
transport monitoring system.
